SMS-BOT COMMAND REFERENCE
=========================
Syntax: <command> [args] [key=value] [+flag] [-flag]
Access is authenticated by the registered sender phone number.

GENERAL
-------
help                          Show all available commands
help <command>                Show detailed help for a command (e.g. help rem)
? <command>                   Alias for help
menu                          Compact dumb-phone menu (alias: m)
1 / 2 / 3 / 4 / 5 / 6       Today / shopping / status / inbox / ideas / help
more / back                   Navigate a long reply
again                         Repeat the previous command
cancel                        Clear navigation state

DUMB-PHONE DASHBOARD
--------------------
today                         Calendar, reminders, weather and solar summary
cam                           Send the latest camera snapshot by MMS
status                        Home entities, solar and service health
agenda [days]                 Calendar events (alias: cal)
news [count]                  RSS headlines (default 3)
bus <destination>             Query the configured transit webhook

STORED MESSAGES
---------------
inbox                         Show counts for messages stored during an outage
inbox sources                 List waiting sources and counts
inbox telegram [group]        Fetch up to 5 Telegram messages, optionally by group
inbox reminders               Fetch reminder overflow not included in the recovery digest
inbox system                  Fetch stored system messages
inbox next                    Fetch the next 5 messages from any source

SHOPPING LIST
-------------
list show                     Display the current shopping list
list add <item>               Add an item to the shopping list
list rm <item>                Remove an item from the shopping list

REMINDERS
---------
rem in <duration> <message>   Create a reminder (e.g. rem in 45m check oven)
t <minutes> <message>         Fast timer (e.g. t 20 pasta)
  Options:
    repeat=<recurrence>       daily | weekly:MON | interval:30m
  Example: rem in 1h take pills repeat=daily

rem list [status]             List reminders (default: active)
  status: active | snoozed | dismissed | completed

rem snooze <id> [duration]    Snooze a reminder (default 10m)
  Example: rem snooze 7 30m

rem dismiss <id>              Dismiss a reminder permanently
d <id>                        Fast dismiss; s <id> [duration] snoozes

NOTES, PRINTING & SAFETY
------------------------
note <text>                   Add text to the ideas note
ideas show                    Show saved ideas
print today                   Print today's agenda
print weather                 Print the weather image
print list                    Print the shopping list
print note <text>             Print an arbitrary note
brief <HHMM|off>              Schedule or disable the daily SMS brief
quiet <HHMM> <HHMM>           Queue proactive SMS during quiet hours
quiet off                     Disable quiet hours
checkin <minutes>             Start a safety deadline; reply OK to acknowledge

ENERGY & SOLAR
--------------
data                          Current inverter power and today's total energy
weather                       Today's weather forecast as text
weather/image                 Today's weather forecast as MMS image
chart                         Today's solar production (Growatt + EcoFlow combined)
chartdays [n]                 Energy per day for last n days (default 7, max 30)

HOME AUTOMATION
---------------
home/dev <entity_id>          Trigger a Home Assistant automation
scene [list|name]             List or run a configured named scene
run [list|name]               List or start a configured orchestrator job

TELEGRAM CONVERSATIONS
----------------------
tg/list                       List recent Telegram conversations (numbered)
  Example output:
    1. Work Group (Emil: are you free?)
    2. Support Chat (Bot: ticket closed)

tg/send <num> <message>       Send a message to conversation #<num> from tg/list
  Also accepts raw Telegram chat_id instead of a number.
  Sets the sticky reply target so tg/reply works afterwards.
  Example: tg/send 1 on my way

tg/reply <message>            Reply to the last active Telegram conversation
  Short alias: r <message>
  Requires a prior tg/send or an incoming relayed message to set context.
  Example: tg/reply sounds good

tg/use <num|chat_id>          Select the conversation for tg/reply and MMS photos
  Alias: tg/target
  The selected target is retained across relay restarts.
  Example: tg/use 1

MMS photo relay:
  1. Send tg/use <num> once, then send a photo to the SIM by MMS.
  2. The MMS text becomes its Telegram caption.
  An MMS caption can override the target: tg/send <num> <caption>

MESSAGE ROUTES
--------------
relay                         List routes, status, and configured targets
relay on [route]              Enable a route; route is optional with one SMS route
relay off [route]             Disable a route; route is optional with one SMS route
  Routes resolve by stable key, 1-based list index, or unambiguous name.
  Examples: relay on
            relay off telegram-to-lora

AI ASSISTANT
------------
ai <message>                  Chat with the AI assistant, or describe what you want to do.
  The AI will try to match your intent to an available command first.
  If no command matches it will respond conversationally.
  Keeps last 5 turns of context per session.
  Example: ai remind me in 30 minutes to check the oven
    → interprets as: rem in 30m check the oven
  Example: ai what's the weather like?
    → conversational response
  Example: ai turn off the living room lights
    → interprets as: home/dev switch.living_room_lights

NOTES
-----
- Commands are case-insensitive.
- Typos of up to 1 character are auto-corrected.
- Named params use = or : separator (e.g. repeat=daily or repeat:daily).
- Flags use + to enable and - to disable (e.g. +verbose).
- Numeric shortcuts can be overridden with user config.sms_shortcuts.
- Named scenes, jobs, status entities and proactive features use per-user config; see sms-bot/README.md.
